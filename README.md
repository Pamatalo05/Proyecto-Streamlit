# 🐍 Proyecto 1 – Python Fundamentals

## 📌 Descripción
Esta aplicación interactiva fue desarrollada como parte del **Módulo 1 – Python Fundamentals** de la especialización en Python for Analytics.

El proyecto integra los principales conceptos aprendidos durante el curso:
- Variables y tipos de datos  
- Estructuras de control  
- Funciones  
- Programación funcional  
- Programación orientada a objetos (POO)  

Todo esto se implementa en una aplicación web construida con **Streamlit**, organizada en diferentes secciones.

---

## 🚀 Funcionalidades

### 🏠 Home
Vista principal con información del proyecto, tecnologías utilizadas y descripción general.

---

### 📋 Ejercicio 1 – Flujo de Caja
Permite registrar ingresos y gastos para calcular:
- Total de ingresos  
- Total de gastos  
- Saldo final  

Indica si el flujo de caja está **a favor o en contra**.

---

### 📦 Ejercicio 2 – Registro de Productos
Gestión de productos utilizando **NumPy**:
- Registro de nombre, categoría, precio y cantidad  
- Cálculo automático del valor total  
- Visualización en tabla con colores por categoría  

---

### 🔢 Ejercicio 3 – Calculadora Financiera
Incluye funciones financieras importadas desde una librería externa:
- Punto de equilibrio  
- Margen neto  
- ROI  
- Valor futuro (interés compuesto)  
- Cuota de préstamo (sistema francés)  

También guarda un **histórico de cálculos**.

---

### 👤 Ejercicio 4 – Gestión de Empleados (CRUD)
Implementación de POO mediante la clase `Empleado`:
- ➕ Crear empleados  
- 📋 Ver empleados  
- ✏️ Actualizar datos  
- 🗑️ Eliminar registros  

Incluye cálculo de salario neto con bonos y descuentos.

---

## 🛠️ Tecnologías utilizadas
- Python 3  
- Streamlit  
- Pandas  
- NumPy
